## How I work

- Config-driven pipelines that are easy to rerun and hand over
- Point-in-time discipline: no look-ahead, no backfill
- Statistical controls where they matter: overlapping windows, multiple comparisons, out-of-sample checks
- Clear documentation so your team can run it without me
